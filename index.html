📖 Panduan ModulKu
👆
Buka/Tutup Menu Ketuk 1x layar atau tombol ☰ di pojok kanan atas untuk memunculkan atau menyembunyikan menu.
📚
Membuka Materi Pilih menu dropdown di atas untuk berpindah modul materi.
📁
Unggah File PDF Klik tombol "📁 File" untuk menambah materi baru ke penyimpanan Supabase.
📱
Bagikan via QR Code Klik tombol "📱 QR" untuk memunculkan kode QR agar bisa dipindai HP lain.
📑
Daftar Isi Klik tombol "📑 Isi" untuk melompat langsung ke halaman bab yang dipilih.
↔️
Membalik Lembaran Usap layar ke kiri / kanan di HP, atau gunakan tombol panah keyboard di laptop.
🤏
Memperbesar Teks (Zoom) Gunakan 2 jari di layar sentuh untuk zoom in/out, lalu geser dengan 1 jari untuk membaca.
